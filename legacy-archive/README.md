# 旧サイト（WordPress）アーカイブ

2026-07-16 のDNS切替まで `mokaruguam.com` で動いていた**旧WordPressサイトの原文**の保管庫です。

## なぜこれがあるのか

旧サイトのファイルは **Xserver 上にしか存在しませんでした**（Wayback Machine にスナップショット無し＝世界で唯一のコピー）。

Xserver はメール（`tour@mokaruguam.com`）で使い続けるため契約は残りますが、**契約が続くこととファイルが残ることは別**です。「Vercelに移したから、この古いWordPressはもう要らない」と数ヶ月後に片付けられれば、原文は永久に消えます。

このディレクトリがあることで、**Xserver 上のWordPressが消えても、記事の原文は1本も失われません**。

## 中身

| 場所 | 件数 | 内容 |
|---|---|---|
| `posts/<slug>.json` | 99 | 全記事。公開中80本＋**非公開19本**を含む |
| `pages/<slug>.json` | 19 | 旧固定ページ（`price` に旧料金、`contact` に旧フォーム等） |
| `categories.json` | 9 | カテゴリ一覧 |
| `media-manifest.json` | 54 | メディアの**一覧のみ**（実ファイルは含まない。下記の注意を参照） |
| `MANIFEST.md` | — | 全記事の目録（状態と非公開の理由つき） |

`content_rendered` は WordPress REST が返した **生HTMLをそのまま**保存しています。**編集しないでください** — 原文の保全が目的です。

## ⚠️ テキストは全て保管済み。ただし画像・動画の実体は未取得

- **記事・固定ページの本文（テキスト）は100%ここにあります。** Xserver上のWordPressが消えても1本も失われません。
- **一方、メディアの実ファイル（画像44・PNG9・動画1＝計54点・約43.8MB）は Xserver 上にのみ存在します。** ここには一覧（`media-manifest.json`）しか無く、実体は入っていません（リポジトリは毎回デプロイでアップロードされるため、43.8MBのバイナリを常設するコストを避けた判断）。
- 復活した記事はこれらを**使っていない**（本文のインライン画像は実質0枚・アイキャッチ0/99）ので、**サイトの表示には一切影響しません**。影響するのは「旧サイトの写真素材そのもの」を将来使いたい場合だけです（車両の写真やチャモロビレッジの写真などが含まれます）。
- **オーナーがXserver上のファイルを整理・削除する前に、この54点をダウンロードして手元に保存することを推奨します。**

## 🔴 このディレクトリは公開されません

- `src/` の外にあり、**どこからも import されていません**（＝ビルドに含まれない）
- `public/` ではないので**配信もされません**
- 記事の公開可否は `src/lib/legacy-articles.ts` の **`LEGACY_SLUGS` 許可リスト**が単独で決めています（`dynamicParams = false`）。ここにファイルを置いても**公開されることはありません**

検証済み（2026-07-17）：ビルド成果物に非公開19本の本文は1文字も含まれず、本番でも19本すべて404。

## 非公開19本の扱い（重要）

**捨てられた訳ではありません。** 状態と理由は `MANIFEST.md` を参照。

- `brand-hold`（5本）… 大麻・ナイトライフ系。**オーナー判断で保留中**。301も410もせず**素の404**のままなので、判断が出ればいつでも復活できます。
- `stale-pricing`（12本）… 本文に**旧料金**（$130/3h・$230/5h・$300/8h・$450/日 等）。現行は `pricing.md` の $170/$250/$345/$500。**料金表記を直せば復活できる資産**です。
- `stale-promise`（2本）… 現在提供していない特典の約束（`repeater-discount` は最大20%OFF、`24hour-support` は24時間対応）。**提供実態を確認して記述を直せば**復活できます。

## 復活させたくなったら

1. 本文の料金・特典の記述を現行の事実に合わせて修正する（オーナー確認）
2. `src/lib/legacy-content.json` にその記事を追加する
3. `src/lib/legacy-articles.ts` の `LEGACY_SLUGS` に slug を足し、`EXCLUDED_*` から外す

URLは旧来どおり `https://www.mokaruguam.com/<slug>`。旧URL（apex＋末尾スラッシュ）からの 308 連鎖がそのまま生きているので、200 を返せば評価は戻ります。

## 更新について

旧WordPressの内容は **2025-09-02 を最後に更新されていません**。原則このアーカイブを再取得する必要はありません。

もし再取得するなら、Xserver は **Host ヘッダで振り分ける共有サーバ**である点に注意してください（`Host: mokaruguam.com` を付ければ 200、無ければ 404。`fetch()` は host ヘッダを黙って落とすため使えず、`node:https` が必要）。**読み取りのみ。書き込み・削除は禁止です。**
